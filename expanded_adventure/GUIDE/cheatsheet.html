Places: the cheat sheet

Every word a place of a sites plugin may use, one line each: what to write in sites.json, how the tool's commands take it, and what it does. Places: sites plugins explains them at length; Reference gives every limit.

Written by tools/adventure_plugin.py guide from game/adventure/plugins/schema_v1.json. Words marked API 3 need "api_version": 3 in plugin.json; the tool's commands set it by themselves.

Conditions

A when is a list; all of it must hold. It may stand on a pane, a line, an action, a result line and a task. On the command line, repeat --when for each.

ConditionIn sites.jsonOn the command lineWhat it does
flag{"flag": "told"}--when "flag=told"The flag is set.
not_flag{"not_flag": "told"}--when "not_flag=told"The flag is not set.
gold_at_least{"gold_at_least": 500}--when "gold_at_least=500"The hero carries at least this much gold.
on_mainland{"on_mainland": true}--when "on_mainland=true"The place stands on the mainland (true) or on an island (false).
used{"used": {"action": "bless", "min": 1, "max": 2}}--when "used=bless:1-2"This site's action was done min..max times.
used_up{"used_up": "bless"}--when "used_up=bless"This site's action has used all its prices.
dungeon{"dungeon": {"dungeon": "vault", "state": "open"}}--when "dungeon=vault:open"The dungeon this plugin raised on this land: none yet, open (still holding cards) or cleared.
has_card API 3{"has_card": {"card": "Black Lotus"}}--when "has_card=Black Lotus"The hero holds at least min copies of the card, in a deck or not.
amulets API 3{"amulets": {"color": "red", "min": 2}}--when "amulets=red:2"The hero carries at least min amulets of the color (any: all colors together).
hero_color API 3{"hero_color": "red"}--when "hero_color=red"The color the hero chose at the start.
owns_magic API 3{"owns_magic": "Dwarven Pick"}--when "owns_magic=Dwarven Pick"The hero owns this World Magic.
food_at_least API 3{"food_at_least": 10}--when "food_at_least=10"The hero carries at least this much food.
gold_below API 3{"gold_below": 100}--when "gold_below=100"The hero carries less gold than this.
day_at_least API 3{"day_at_least": 30}--when "day_at_least=30"The journey's day is this or later.
wizards_defeated API 3{"wizards_defeated": 2}--when "wizards_defeated=2"At least this many of the five wizards are beaten.
at_peace API 3{"at_peace": true}--when "at_peace=true"Arzakon is banished and the hero walks on (true), or not yet (false).
difficulty API 3{"difficulty": {"min": 0, "max": 1}}--when "difficulty=0-1"The campaign's difficulty, 0 (the easiest) to 3, is within min..max.
plugin_on API 3{"plugin_on": "old_hut"}--when "plugin_on=old_hut"The plugin of this id is part of the campaign and enabled; a plugin not installed is not.
counter API 3{"counter": {"name": "wins", "min": 3}}--when "counter=wins:3"The counter (declared in sites.json counters) is within min..max.
site_used API 3{"site_used": {"site": "hut", "action": "secret"}}--when "site_used=hut.secret"The action of another place of this plugin was done min..max times.
gift_waiting API 3{"gift_waiting": false}--when "gift_waiting=false"A gift for the next duel (extra life, the first move or a card in play) already waits (true) or none does (false).
any API 3{"any": [{"flag": "told"}, {"gold_at_least": 500}]}--when "flag=told | gold_at_least=500"At least one of these holds. No any inside an any.

Effects

The effects of an action that does effects or talk, of a duel's win and lose, and of a roll's outcomes, applied in order once the price is paid.

EffectIn sites.jsonOn the command lineWhat it does
set_flag{"set_flag": "told"}--effect "set_flag=told"A flag declared in quests.json flags (an island) or sites.json flags (a sites plugin).
clear_flag{"clear_flag": "told"}--effect "clear_flag=told"A flag declared in quests.json flags (an island) or sites.json flags (a sites plugin).
gold{"gold": -100}--effect "gold=-100"
food{"food": 6}--effect "food=6"
log_clue{"log_clue": {"text": "shrine.bless_clue"}}--effect "log_clue=The old man told you of a vault."
log_event{"log_event": {"event": "shrine", "text": "shrine.bless_log"}}--effect "log_event=Paid at the shrine."
spawn_dungeon{"spawn_dungeon": "vault"}--effect "spawn_dungeon=vault"Raise the named dungeon on this land, its place, creatures and rules known, unless it is open there already.
counter API 3{"counter": {"name": "wins", "add": 1}}--effect "counter=wins+1"Add to a counter, or set it (one of add, set); it stays within 0..1000.
amulet API 3{"amulet": {"color": "red", "count": 1}}--effect "amulet=red"Give (or take) amulets of a color; the hero never carries fewer than 0 or more than 99 of one. Giving needs prices or needs on its action.
give_card API 3{"give_card": "Shivan Dragon"}--effect "give_card=Shivan Dragon"One copy of the card into the hero's bag. Refused before anything is paid when the bag is full or the campaign's card rules allow no more copies. Needs prices or needs on its action.
next_duel API 3{"next_duel": {"life": 5}}--effect "next_duel=life:5"A gift for the hero's next duel, one of: life (extra life), first_move true, card (begins in play). Refused before anything is paid while a gift already waits.
roll API 3{"roll": {"outcomes": [{"weight": 3, "result": ["den.lost"]}, {"weight": 1, "effects": [{"gold": 150}], "result": ["den.won"]}]}}--outcome "3 | | You lose." --outcome "1 | gold=150 | You win!"One outcome by its weight, drawn on the plugin's own dice for this land, place, action and use (the same after a reload): its effects are applied and its result lines shown after the action's. One roll an action, none inside a roll or a duel's win or lose.
reveal_map API 3{"reveal_map": {"around": "place", "radius": 4}}--effect "reveal_map=place:4"The map uncovered within radius tiles of this place, or of dungeon:<a dungeon of this plugin> once it is raised.

Actions

A button of a pane. Its do says what it does: effects: pay and apply the effects; copy_card: pay and copy one of the hero's cards they pick; leave: close. API 3: talk: open the pane named by to (after paying and applying effects, when it has any); duel: pay the stake and fight foe, then win or lose; buy_card, sell_card: trade one of cards for gold.

doIn sites.jsonOn the command lineWhat it does
effects{"id": "bless", "do": "effects", "label": "shrine.bless", "prices": [20, 40], "effects": [{"food": 6}], "result": ["shrine.blessed"]}add-action FOLDER --place shrine --id bless --prices 20,40 --effect food=6 --label "Leave {price} gold" --result "Your pack is heavier."
copy_card{"id": "copy", "do": "copy_card", "prices": [500, 1000], "result": ["tower.copied"]}add-action FOLDER --place tower --id copy --do copy --prices 500,1000 --result "A copy of {card} is yours."
leave{"id": "leave", "do": "leave", "label": "shrine.leave"}(every pane the tool writes has one)
talk API 3{"id": "ask", "do": "talk", "to": "rumors", "label": "inn.ask"}add-pane FOLDER --place inn --id rumors --line "They say..."; add-action FOLDER --place inn --id ask --do talk --to rumors --label "Ask for rumors"
duel API 3{"id": "duel", "do": "duel", "foe": "champion", "prices": [50, 50], "win": {"effects": [{"gold": 100}], "result": ["ring.won"]}, "lose": {"result": ["ring.lost"]}}add-foe FOLDER --id champion --name "The Champion" --deck deck.txt; add-action FOLDER --place ring --id duel --do duel --foe champion --prices 50,50 --win-effect gold=100 --win "You win." --lose "You lose."
buy_card API 3{"id": "buy", "do": "buy_card", "cards": {"Shivan Dragon": 400}, "stock": 1}add-action FOLDER --place stall --id buy --do buy --cards "Shivan Dragon=400" --stock 1
sell_card API 3{"id": "sell", "do": "sell_card", "cards": {"Black Lotus": 900}}add-action FOLDER --place stall --id sell --do sell --cards "Black Lotus=900"

Costs

"prices": [20, 40, 80]: the gold each use costs, in turn; after the last price the button is gone. "prices": [0]: free, once. No prices: free, and never used up. needs is what the action takes besides gold, each time; the button is refused, and nothing paid, while the hero lacks one.

NeedIn sites.jsonOn the command lineWhat it does
card API 3{"card": "Black Lotus"}--needs "card=Black Lotus"One copy of this card is handed over (one in no deck first; else it leaves its decks).
amulets API 3{"amulets": {"color": "any", "count": 3}}--needs "amulets=any:3"Amulets of a color, or of any (taken from the color the hero has most of first).
food API 3{"food": 5}--needs "food=5"Food.

Lines

The lines of a pane and the result of an action are lists of these.

LineIn sites.jsonWhat it does
a text key"shrine.intro"The sentence of text.json under that key.
a line with a when{"text": "shrine.again", "when": [{"used": {"action": "bless", "min": 1}}]}Shown only while its conditions hold.
one_of API 3{"one_of": ["inn.rumor1", "inn.rumor2", "inn.rumor3"], "by": "day"}One of the texts, in turn: the next one each day, or with "by": "uses" each time an action of the place is done. No dice.

Fields

Every field of sites.json, of a pane and of an action.

FieldOfWhat it is
saltsites.jsonMixed into the dice that place the sites and their dungeons, so two plugins never stand on the same tiles by the same draw.
flagssites.jsonThe plugin's own flags, all off at the start of a campaign.
picturessites.jsonPicture keys (each beginning with the plugin id and _) to their files.
dungeonssites.jsonThe dungeons a site's spawn_dungeon can raise, by key.
counters API 3sites.jsonThe plugin's own counters, each a whole number from 0 to 1000, all 0 at the start of a campaign.
foes API 3sites.jsonThe opponents a duel action names, by key: a fixed deck, life and face, never scaled to the hero.
tasks API 3sites.jsonRows for the Tasks pane, each with a place on the map to guide the hero to.
sitessites.jsonThe places, by id.
whena paneThe first pane without an id whose conditions hold is shown. The last pane without an id has no when.
id API 3a paneA pane with an id is never chosen by itself: a talk action opens it by its to.
titlea paneDefault: the site's name.
subtitlea paneDefault: the plugin's name.
picturea paneDefault: the site's picture.
linesa pane
actionsa pane
idan actionThe action's own name in its site: its uses are counted by it.
doan actioneffects: pay and apply the effects; copy_card: pay and copy one of the hero's cards they pick; leave: close. API 3: talk: open the pane named by to (after paying and applying effects, when it has any); duel: pay the stake and fight foe, then win or lose; buy_card, sell_card: trade one of cards for gold.
labelan actionThe button; {price} and {uses_left} are filled.
whenan actionAll must hold.
pricesan actionThe gold each use costs, in turn; once all are used the action is gone. Empty: free, and never used up.
effectsan action
resultan actionThe lines shown once the action is done; none: the place's pane again.
pick_titlean actioncopy_card, buy_card, sell_card: the card list's title.
pick_linean actioncopy_card, buy_card, sell_card: the line under it.
needs API 3an actionWhat the action takes besides gold, each time; the button is refused, and nothing paid, while the hero lacks one. Not on leave, buy_card or sell_card.
to API 3an actiontalk: the id of the pane of this place to open.
foe API 3an actionduel: a key of sites.json foes.
win API 3an actionduel: what a win brings.
lose API 3an actionduel: what a loss or a draw brings.
count API 3an actionduel: when a use is counted (and the next price of prices is reached): each time the duel is begun, or only when it is won. The price is paid each time either way.
cards API 3an actionbuy_card, sell_card: each card and its price in gold. The game never sells a card for less, nor buys one for more, than the most a town pays for it.
stock API 3an actionbuy_card, sell_card: how many of each card are traded in a campaign. Default: without end.

Recipes

A whole place, valid and walkable, whose sentences you then rewrite: python3 tools/adventure_plugin.py add-place FOLDER --id KEY --name NAME --recipe RECIPE.

RecipeWhat it makes
lorea place that tells: a rumor that changes by the day, and a tale behind a talk button
gifta gift given once: food and an amulet, or a card with --card
healera blessing for the next duel behind three prices, and food for gold
tolla gate that opens for gold, for an amulet, or for a hero of one color (--color)
gamblerfive throws of the dice at 50 gold: a roll of three outcomes and a counter of plays
riddlea riddle with three answers: talk panes, a counter of wrong tries, gold for the right one
collectorsomeone who wants a card (--card) and pays for each copy the hero hands over
duelista duel for a wager of gold against the place's own champion, and a counter of wins
shopa stall that sells a few cards and buys one
questan errand: accept it, bring a card (--card), be paid; with a row in the Tasks list
