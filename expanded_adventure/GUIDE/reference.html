Reference

Every file, field, kind, limit, condition, effect and placeholder of adventure plugin API 1, as the game reads it. The game and the authoring tool read the same schema, so what this page says is what validate checks.

plugin.json

The manifest. Any field not listed here refuses the plugin, so a misspelled field is named, not ignored.

FieldKindRequired / defaultLimitsWhat it is
plugin_formatintrequiredalways 1The manifest's own format.
api_versionintrequiredfrom 1; this game reads API 1The plugin API it is written for; a newer one than the game reads refuses it.
idstringrequiredmatches ^[a-z][a-z0-9_]{0,39}$; never mainlandThe plugin's identity: saves name it, picture keys begin with it. Never change it.
namestringrequired1 to 100 charactersThe name in the plugin list.
versionstringrequired1 to 4 numbers joined by dotsThe plugin's version, like 1.0.0.
minimum_game_versionstringoptionalnumbers and dotsThe oldest game version that reads it; an older game refuses it.
authorslist of stringrequired1 to 16 names, each up to 100 charactersWho made it.
licensestringoptionalup to 4000 charactersIts license, in a few words.
descriptionstringrequiredup to 300 charactersOne line for the plugin list.
learning_notestringoptionalup to 4000 charactersA dimmer line under the description (the prototype says it is a learning demo).
requiresobjectoptionalcard_packs: up to 16 of {"id": "pack-N", "min_version": "1.0"}The card packs it needs; never Pack 1. A plugin never withholds or unlocks their cards.
regionobjectrequiredtitle (required), castle_name, salt (0 to 2147483647), mana_links, paletteThe island: its title, the castle's name, the salt that makes its island its own, whether mana links work there, its palette (shandalar, last_refuge, or a palette object).
filesmapoptionalfile -> 64 lower-case hex digitsWritten by export: the SHA-256 of every other file; any change after export refuses the plugin.

Placeholders

A text of text.json may hold these, in braces; the game fills them in. Any other {word} refuses the plugin.

PlaceholderWhat it says
{pledges}quests completed in this region
{quests_total}quests in this region
{target}the name of where the current step leads (or the next target)
{town}the quest's giver town
{title}the quest's title
{foe}the foe's name
{life}the foe's life
{count}a count: matching deck cards, waiting cards, reward choices or cards collected
{total}the main deck's nonland cards
{required}the matching nonland cards the deck gate needs
{percent}the deck gate's percentage
{left}cards still held after collecting
{color}a reward bundle's label
{cards}a reward bundle's offered cards, comma separated
{hero}the hero's name
{region}the region's title
