Text and placeholders

Every sentence, title and button of a plugin lives in text.json, by key. The other files name keys, never words, so the story can be read and corrected in one place.

text.json

One flat object: key to words. A key is 1 to 64 lower-case letters, digits, _ and .; the dots are only for your own grouping. There may be up to 2,000 keys, each text at most 4,000 characters. A field whose kind is text in the Reference holds a key, and a key named anywhere must exist, or the plugin is refused, naming the place that asked for it.

Words may hold \n for a new line. Write in American English (“color”, “harbor”); API 1 reads only text.json, and the name text.<language>.json is kept for translations in a later version.

Placeholders

A word in braces, like {pledges}, is replaced where the text is said. The list is closed; a {word} of lower-case letters, digits and _ that is not on it refuses the plugin. Braces around anything else ({ }, {Hero}) are left as written. Nothing in a text is ever evaluated.
