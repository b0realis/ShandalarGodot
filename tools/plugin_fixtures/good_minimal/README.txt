Corpus Isle
===========

An adventure plugin for Shandalar, made with tools/adventure_plugin.py new.

Edit the JSON files, then check and package the plugin:
    python3 tools/adventure_plugin.py validate corpus_isle
    python3 tools/adventure_plugin.py export corpus_isle --out dist
Put the zip (or this folder) in the game's expanded_adventure/ folder and tick it
in the Embark window's plugin list. The guide in expanded_adventure/GUIDE/
explains every file and field.
