Getting Started with Shandalar

From download to your first duel: the game with its original 1997 look, a picture on every card, and every card set up to the Urza block. Nothing else to install: the game fetches the card pictures itself, and you wait.

  • About 45 minutes, mostly waiting
  • About 3 GB of free space
  • An Internet connection
My computer:
0 of 6 steps done

Card pictures can't come with the game, because they aren't ours to hand out. So the game downloads them itself, from Scryfall, onto your own computer. The packs that add the later sets are made the same way, because they carry those sets' pictures. Pick your computer in the bar above and this page shows only your steps. For an iPad or a web browser, see iPad and web play further down.

  1. 1

    Download the game

    Open the downloads page. Under Assets, click the file for your computer that ends in -with-skin.zip. That one has the original look and sounds.

    Open the downloads page

  2. 2

    Unzip it and find the game folder

    Right-click the zip and choose Extract All…, then Extract. The game won't run from inside the zip.

    Double-click the zip. A folder appears next to it.

    Right-click the zip and choose Extract Here.

    Move the folder somewhere easy to find, such as Documents. The game folder is the one with Shandalar.exeShandalar.apprun.sh in it.

    Windows makes a folder named after the zip and puts the game folder inside it. Go one folder deeper.

  3. 3

    Start it once

    Double-click Shandalar.exe. The first time, Windows may warn you, because the game isn't signed by a company. Click More info, then Run anyway.

    Double-click Shandalar.app. The first time, macOS stops it because the game isn't from the App Store. Close the message, then let it through once in System Settings.

    Older macOS versions word these a little differently, but the Open Anyway button is in the same place.

    Double-click run.sh (if your file manager asks, choose Run), or start it from a terminal with ./run.sh.

    You'll see the main menu. You can already play the 897 original cards; they just have no pictures yet. Leave the game open for the next step.

  4. 4

    Get the card pictures and the card sets Key step

    In the main menu click Options, scroll down to Card packs and click the purple Get Card Packs... button. Tick what you want and press OK. The game does the rest.

    The 1997 card pictures put a picture on each of the 897 original cards. Packs 1 to 10 add the later sets, up to the Urza block, with their pictures. The window says how much each one downloads and how much free space it needs.

    Now wait. Everything together is about 1 GB to download and takes about half an hour: the pictures come from Scryfall, one at a time, at a pace that is kind to its servers. A bar shows how far it is and how much time is left. You can use your computer meanwhile.

    Stopped early, or the connection dropped? Nothing is lost. Open Get Card Packs... again, tick the same packs and press OK: what was already downloaded is kept, and it goes on from there.

    At the end the window lists what was installed. The game keeps the finished zip files in its own card folder; you don't have to move, unzip or rename anything.

    No purple button? It comes with version 0.70.11 or later. The version number is in the bottom right corner of the main menu. On an older version, download the newest one (step 1), or use the other way below.
    The other way: the Python tools

    The game folder has a tools folder with small programs that make the very same zip files from a command window. They need Python 3.10 or newer (free, from python.org). You only need them on an older version of the game, or if you like the command line.

    The commands for each pack, and where the zip files go, are in the card art and packs guide. Then go on with step 5 here.

  5. 5

    Switch the packs on

    In Options, click Card Packs... (beside the purple button), and click Enable under each pack.

    The card pictures need nothing more: they show by themselves, at the latest after the next start of the game. If a pack is missing from the list, click Rescan.

  6. 6

    Play

    Magic Battle starts a duel against the computer: pick a deck for each seat and click Go! Shandalar starts the adventure.

    To play with the new sets, make a deck that uses them:

    2. →
    3. Extras
    4. →
    5. switch on the sets
    6. →
    7. Deck → AutoDeck
    8. →

    10. →

    Extras picks which sets the Deck Builder shows: 1997 at its top shows the original cards alone, All switches every set on (or, when all are on, off), and each set's Only shows that set alone. AutoDeck, the gold line at the top of the Deck menu, builds a deck for you from the sets and colors you choose; you can also build one card by card. Then pick your deck in Magic Battle.

    Rather play with a controller? From version 0.70.11 the whole game answers one: the left stick moves the pointer, A presses, B closes or goes back, and the D-pad walks your hero on the adventure map and jumps from button to button in menus. Options → Controls shows every button and lets you change it. With no controller connected, nothing changes.

iPad and web play

The game also runs in a web browser, and so on an iPad, with no app store. It works like a small website of your own: you put the game's web download on a web host, open its address in Safari on the iPad, and add it to the Home Screen. From then on it has its own icon, opens full screen and can play without a connection.

Keep it to your household. The 1997 skin inside the -with-skin downloads is offered with the release for your own play: put it on a host that only you and your household use, not on a public site for other people. Card pictures and card packs are never part of any download; they are yours alone to add, and never belong on an address other people can reach. On any other host, upload the game without the skin and add skin and card pictures on the iPad itself (step 6 below).
  1. 1

    Download the web version

    On the downloads page, under Assets, take the file that ends in -web-offline.zip, and unzip it on your computer.

    Open the downloads page

    • web-offline is the one for an iPad: it saves the game on the iPad, so it starts without a connection.
    • web-offline-with-skin is the same with the 1997 look already inside, for your own play. Use it on a host that only you and your household use.
    • web is the same game without the offline saving: it plays only while the iPad can reach your host.
    • web-threaded needs a specially set up web server. Skip it.

    The unzipped folder is a complete little website: index.html and the game's files beside it. Keep them all together.

  2. 2

    Try it on your computer first

    A browser plays the game only from a web address. Double-clicking index.html shows an error, or nothing. One line turns your computer into a tiny web server for a test.

    It needs Python, which is free. Get it from python.org/downloads and keep the default choices.You very likely have it already. Then open a command window in the unzipped web folder:

    Open the folder in File Explorer, click the address bar at the top, type cmd and press Enter.

    Open Terminal (in Applications → Utilities), type cd and a space, drag the folder from Finder onto the window, and press Enter.

    Right-click an empty spot inside the folder and choose Open in Terminal.

    Type this line and press Enter:

    Now open http://localhost:8000/ in the browser on that same computer. The game's main menu appears. To stop the server, close the command window.

    This address is only for the computer itself. An iPad can't use it, and it can't use your computer's home network address (one like http://192.168.…) either: browsers run the game only from an address that starts with https://. The one exception is localhost, on the computer that runs the server.
  3. 3

    Put the folder on a web host Key step

    Upload the whole unzipped folder, as it is, to a web host of your own. Any host that serves plain files will do: the game needs no database, no login and no programs on the server.

    What must be true of the host:

    • Its address starts with https://.
    • The game has a folder of its own there, and every file of the download is in it, unchanged.
    • The address stays the same. Everything the iPad keeps (step 5 and after) belongs to that one address.
    • It hands out files as they are. Most hosts do. If yours has settings for it: .wasm files go out as application/wasm, a missing file is not answered with index.html, and offline-sw.js is not cached by the host (Cache-Control: no-cache).

    No special security headers are needed for web-offline and web. (Only the web-threaded download needs them, which is why this guide skips it.)

    A server in your own home works as well, as long as it gives the game an https:// address. Whichever you use, remember the box at the top of this chapter: a download with the skin only on a host for you and your household, and card pictures never where other people can reach them.

  4. 4

    Open it on the iPad and add it to the Home Screen

    On the iPad, open Safari and go to your host's https:// address. The main menu appears, just as on the computer.

    Now give it an icon: tap Safari's Share button, then Add to Home Screen. If you see an Open as Web App switch, leave it on. The game's own icon lands on the Home Screen. The wording may differ slightly between iPadOS versions.

    From now on, always start the game from that icon. It opens full screen, without Safari's bars, and turned sideways (landscape), the way the table is laid out. The icon keeps its own skin, decks and saves, apart from what a Safari tab keeps; so set everything up in the game you opened from the icon.

  5. 5

    Let it save itself for offline play

    Open the game from its icon while the iPad is still connected, and leave it open for a few minutes. In the background it saves its files on the iPad: about 50 MB, or about 130 MB with the skin.

    Nothing on the screen says when this is finished, and seeing the main menu does not mean it is. So test it: close the game completely, switch on Airplane Mode, and open the icon again. If the main menu comes and a duel starts, the iPad has everything, and your host no longer needs to be reachable. If not, reconnect, open the game and give it more time.

    A new version. The iPad gets new versions from your host, not from the downloads page. Download the new web-offline zip, unzip it, and replace the files on your host, all of them together, at the same address. The next time the game is opened with a connection, it fetches the new version in the background. Close the game completely and open it again, and the new one starts. The version number is in the bottom right corner of the main menu. Your decks, saves, skin and card pictures stay.

    Starting clean. Clearing the website data for your host's address in the iPad's Safari settings removes the saved game and everything else it kept there: skin, card pictures, decks and adventures. Export your adventures first (step 7).

  6. 6

    Add the 1997 look and the card pictures

    Without them the game draws clean panels of its own and plain cards, and plays the same. To add them you need two zip files on the iPad, then Options → Skin → Choose...

    • The skin: original_skin.zip, a download of its own on the downloads page, or the skin zip you made on your computer from your own 1997 game.
    • The card pictures: cardart.zip. Make it on your computer with Get Card Packs... (step 4 at the top of this page; tick 1997 card pictures). It is then in the game's card folder: Options → Card Packs... → Open Folder shows it.

    Copy both to the iPad, into the Files app, any way you like. In the game on the iPad, open Options; under Skin there is a Choose... button for the skin and one for the card art. Tap it, pick the zip, and wait until the game has read it in; the files are large (about 110 MB and 190 MB). Restart the game when it offers to. The game keeps its own copy, so the zips in Files can go afterwards, but keep them somewhere: you'll need them again if the iPad ever clears the game's data.

    Forget my zips, under Skin, removes the zips you added.

    The browser version plays the 897 original cards. The numbered packs with the later sets can't be added to it; they are for the computer and handheld versions.

    On a host only you and your household use: the zips beside the game

    There, the two zips may sit on the host instead: as skin/original_skin.zip and skin/cardart.zip in the game's folder, beside index.html. The game fetches them by itself and keeps them. For the web-offline download, run py -3 tools/package_web_offline.py --refresh .python3 tools/package_web_offline.py --refresh . in the folder after adding or changing a zip and before uploading, so the offline copy includes it. Never put card pictures on an address other people can reach.

  7. 7

    Look after your saves

    In a browser there are no folders. Your adventures, decks, options, skin and card pictures live in the browser's own storage for your host's address, on that one iPad.

    That storage is not a safe place for the only copy. Clearing website data deletes it, an iPad that runs low on space may clear it by itself, and a Home Screen icon is not a backup. So now and then, and always before you clear anything or move the game to a new address:

    Open Save / Load in the main menu, highlight a save of the adventure and press Export. The whole adventure, every save of it, downloads as one file. Import on the same screen brings it back, on this iPad or on any computer with the same version of the game or a newer one.

    A duel that is under way is not kept when the game is closed. Finish it, or give it up, first.

  8. 8

    What is different on an iPad

    • You play by finger. A tap is a click. Hold, then lift, is a right-click. Drag to drag, swipe to scroll a list, and tap the large card to see it full screen. Options → Display → Touch controls is Auto, On or Off; leave it on Auto.
    • No keyboard, mouse or controller is needed. Touch always works, and text fields bring up an on-screen keyboard. A controller paired with the iPad should act as it does on other devices; this has not been tested on an iPad.
    • Hold the iPad sideways. The table is laid out for landscape.
    • The 897 original cards, the adventure, duels, the Deck Builder and Booster Draft are all there.
    • Not in the browser: games over the local network (Host on LAN, Find LAN games), Get Card Packs..., Build from a 1997 install..., the numbered card packs, the adventure plugins that come with the computer downloads, and anything that opens a folder.

    The same steps work for an Android tablet or any computer's browser: open the address, and choose Install app or Add to Home Screen where the browser offers it.

If something goes wrong on the iPad

A white or empty page, or an error instead of the game

Check the address: it must start with https:// (step 3). A file opened from the Files app, or an http:// address of a computer on your home network, does not run the game. Check that every file of the download is on the host, in one folder. Then give it a moment: the first load fetches the whole game. The game needs a browser with WebGL 2, which very old iPads lack.

The old version still shows after an update

Open the game with a connection and leave it open for a few minutes, then close it completely (swipe it away in the app switcher, and close any Safari tab that has it open) and open it again. A new version waits until no window of the old one is open. Also check that all the new files went to the host together, at the same address.

It says to reconnect, or it won't start without a connection

The offline copy is incomplete: it wasn't finished, or the iPad cleared part of it. Connect, open the game and leave it open until it has fetched the files again, then close it completely and reopen. Your saves are kept apart from the game's files and are not touched by this.

The skin, the card pictures or my saves are gone

The iPad cleared the game's storage: it was full, or website data was cleared. Make room, then add the zips again (step 6) and Import your exported adventures (step 7). If you started the game from a Safari tab instead of the icon, nothing is lost: the two keep separate storage, so open it the way you did before.

Nothing is kept from one visit to the next

Don't use Private Browsing: it forgets everything when the tab closes. Use the Home Screen icon.

Choosing a zip seems to do nothing

Large zips take a while to read in; a line under the buttons says how far it is. Only a skin zip and a card art zip are taken; a numbered pack zip is refused.

If something goes wrong

Most problems take one step to fix. For the iPad and the browser, see the end of the chapter above.

There is no purple Get Card Packs... button in Options

The button comes with version 0.70.11 or later; the version number is in the bottom right corner of the main menu. Download the newest version (step 1), or use the Python tools (the other way, in step 4).

The download stopped, or the window says Not finished or Not started

The connection dropped, or the download server was busy. Check the connection, open Get Card Packs... again, tick the same packs and press OK: what was downloaded is kept, and it goes on from there.

Not enough free disk space

The window says how much the ticked packs need and how much is free. Make room, or tick fewer packs now and the rest another day.

A pack is missing on the Card Packs page

Click Rescan. Packs made in the game are in the folder named at the top of that page. Packs made with the Python tools belong in a cardpacks folder inside the game folder, next to Shandalar.exeShandalar.app (never inside it)run.sh. Either way the zips must keep their names.

The cards still have no pictures

Open Get Card Packs... and check that 1997 card pictures was built; if not, tick it and press OK. Then start the game again.

The game looks plain, or says No 1997 skin

You have the download without -with-skin. The game plays the same, in plain panels of its own. For the classic look, take original_skin.zip from the downloads page and pick it with Choose... under Skin in Options. Or, from version 0.70.11, make the skin from your own copy of the 1997 game: Build from a 1997 install..., under the skin in Options, reads the folder it was installed to, its CD or a CD image, and keeps the skin as classic_no-video.zip.

Permission denied when starting run.sh

Your unzip tool dropped the “executable” mark. In a terminal in the game folder, run chmod +x run.sh Shandalar.x86_64.

Where are my saves? Can I take them to another computer?

Your adventures are in an adventures folder, beside your decks (decks) and options (settings.cfg):

%APPDATA%\Godot\app_userdata\Shandalar\adventures — paste it into File Explorer's address bar.

~/Library/Application Support/Godot/app_userdata/Shandalar/adventures — in Finder, choose Go → Go to Folder… and paste it.

~/.local/share/godot/app_userdata/Shandalar/adventures — the same on a Steam Deck.

A portable game (Options → Portable game, or started with Shandalar-portable.bat) keeps all of this in a portable folder inside the game folder instead.

Each adventure is a few files starting with the hero's name: its autosave, its Quickslot and its named slots, each with a .bak copy. To play it on another computer, copy them all into the same folder there, and use the same version of the game or a newer one, with the same card packs.

Easier, and the same everywhere: open Save / Load, highlight a save of the adventure and press Export. The whole adventure, every save of it, becomes one file, Shandalar adventure - hero - date.zip, wherever you choose; on a phone or a headset, choose Downloads. On the other computer or device, press Import on the same screen and choose that file. The game checks it all before it writes anything, and asks before it replaces an adventure that's already there.

On Android the saves are in Android/data/com.b0realis.shandalar.android/files/adventures, and on the Meta Quest in Android/data/com.b0realis.shandalar/files/adventures. With USB debugging on, adb pull copies that folder to a computer, as does a file manager that's allowed into Android/data. The browser version keeps its saves in the browser: Export downloads the file, and Import takes one from your device. See iPad and web play.

A new version is out

Download and unzip it as in steps 1 and 2, and start the new one. Your decks, adventures and options are kept outside the game folder, and so are the card pictures and packs made with Get Card Packs...: there is nothing to copy. If you made them with the Python tools, copy skin/cardart.zip and the cardpacks folder from your old game folder into the new one. A portable game keeps everything in its portable folder: copy that folder into the new game folder. If the Card Packs page says a pack needs rebuilding, build it again with Get Card Packs...
