# Bug pass — 2026-10-03

A whole-tree bug hunt on 0.50.6, then a fix pass, then a second look at
the MCP server (`tools/shandalar_mcp.py`) and the referee behind it.
Started from clean `d075a0d` with the gate green (550 scripts, 8,310
tests, Python 430). Nine read-only hunters covered the tree by area
(`engine/mtg_game.gd`; the rest of `engine/`; `engine/ai/`; the core
card sets; the six expansion packs; `game/duel/` + `game/input/`; the
shell screens and the Deck Builder; `game/sgmanalink/`; `DeckLab/` and
`tools/`), each finding reproduced with a probe where it could be. Fixes
were made test-first: every regression below failed for the reported
reason before its fix.

New regression scripts (the rest went into the existing scripts that
cover the code):
`tests/ai/test_bug_pass_2026_10_03_ai.gd`,

## The worst of what was found

- **Simultaneous losses had a winner.** Both libraries emptied by one
  Wheel of Fortune, or both players killed by one Psionic Blast / Fire
  and Brimstone / Mana Clash, gave the game to whoever was hit second
  (CR 104.4a, 704.3). An empty-library draw is now judged with life and
  poison in one state-based check, and a resolution defers its checks
  until it has finished.
- **A LAN client could double its combat damage** by naming one creature
  twice in `attack_bands` (or in two bands); the engine stored the bands
  unchecked.
- **Deck Lab heap corruption.** In-process Lab runs raced the AI's and
  the undo/snapshot static caches across `WorkerThreadPool` threads
  ("double free or corruption", reproduced 4/4). Every lazily filled
  static cache in `engine/ai/effect_intent.gd`, `engine/undo_log.gd` and
  `engine/game_snapshot.gd` is now behind a mutex.
- **Hidden information.** The Duel Log window and `duel_log.txt` printed
  the AI's private Demonic Tutor find and Sylvan Library's cards (engine
  log lines now carry `private_to` / `public` meta, and the screen prints
  the public sentence to anyone who may not see that seat); Clone,
  Vesuvan Doppelganger and Dance of Many copied — and named — the card
  under an Illusionary Mask (now a nameless 2/2, CR 707.2/708.2); the
  stack's "(targeting …)" label named face-down targets; the AI read a
  face-down permanent's real name and supertypes when judging a legend.
- **The mana planner refused payable two-colour costs** depending on pip
  order (`{U}{B}` vs `{B}{U}` with two duals) — wrong "unless you pay"
  sacrifices, castable marks, auto-pay and AI play. Coloured pips are
  now matched, not taken greedily.
- **The AI killed itself or helped the opponent**: tapped several pain
  lands to death for one spell; an unpayable Fog in hand blocked every
  other combat answer; shrink effects (Contagion, Shrink) aimed at its
  own creatures; +X/-Y self-pumps bought until the creature died.
- **Player data loss**: a hand-edited `settings.cfg` that no longer
  parsed lost every key after the bad line on the next save (now copied
  to `settings.cfg.bad` first); decks and settings were truncated in
  place (now written atomically); several Deck Builder flows discarded a
  slot's unsaved deck without asking.
- **SGManalink**: OK on a friendly duel's result closed the whole lobby
  and, on a host, every other table; a peer could pin ~1.3 GiB on the
  host through the replay cache; a different protocol version failed in
  silence (now named, both ways, across the subprotocol bump).
- **No skin, no graveyard**: without the imported 1997 art the graveyard
  and exile piles were not clickable, so Raise Dead could not be aimed.

## The MCP server, again

- A `lab` call without `out` returned only the report: the run folder
  was searched for on stderr while the Lab names it on stdout. Runs now
  default to `workspace/runs/lab-STAMP` (where the docstring and
  `.gitignore` always said a client's runs go) and answer with `run`,
  `results` and `next`.
- Calls run on a worker thread: `ping` is answered at once and
  `notifications/cancelled` kills the call's process group (the Lab's
  workers too) and suppresses its answer; SIGTERM does the same before
  the server ends. A cancelled fifteen-minute Lab run used to hold every
  later request behind it.
- A `KeyError` inside a tool was reported as "unknown tool"; a half
  written `run.json` was a protocol error instead of a refusal; two
  servers on one workspace could both number a game `g1`; a kept-game
  socket closed while booting could still connect; `status` parsed every
  kept transcript whole (now its tail); the deck reader differed from the
  engine's (BOM, `// NAME :`, `0 Card`); deck rows over the engine's
  500-copy limit are refused before a file is written.
- The referee's kept-game socket decoded each TCP read on its own, so a
  character split across two reads was garbled; it now decodes whole
  lines (and the server sends ASCII).

## The owner's rulings (2026-10-03)

- **Default duel portrait: the library face**, as the setup screen shows
  it — a seat that never chose one plays with the library's face for that
  seat (`SetupScreen._chosen_portrait`), not the deck-colour duelist.
- **Land-taxed attacks stay as priced**: with the damage high and mana to
  spare, trading lands for damage under Flooded Woodlands or Reclamation
  is a fair play.
- **Leaving a LAN table at the turn limit concedes** (deliberate since
  0.40.31): a local referee duel past `--turns` is a draw, a table one is
  a loss.

## Second round — what was left, done

- **Face-down creatures in the log, every line.** Rather than ~330
  writers each asking, `MtgGame.log_line` reads the line: one that names a
  face-down permanent is private to its controller (`private_to`, and
  `public` with the name replaced); a line naming both seats' masked
  creatures is `FACE_DOWN_NOBODY`'s, read whole only where every hand is
  open. The meta names no card for a line about a face-down permanent.
- **Axelrod Gunnarson** ranks "opponent first" for his TRIGGER's
  controller: `MtgGame.controller_acting_for` also answers while a
  trigger's targets are ranked (a stolen Axelrod that died in the wave
  used to aim at the thief).
- **Voodoo Doll's ledger row lifted**: `CardInstance.last_tapped` is a
  last-known value like `last_counters`, so a Doll tapped in response and
  then removed no longer backfires (CR 603.4).
- **Eureka's ledger row lifted**: Animate Dead and Dance of the Dead are
  offered and choose a creature card in a graveyard as they enter (CR
  303.4f); `attach_aura_from_anywhere` takes a graveyard host for those two
  shapes, raising it the way each does when cast.
- **The Lab: `--progress json`** (one JSON line a second on stderr) and
  the chrome flags (`--quiet`, `--no-banner`, `--progress`) taken beside
  `--resume` without entering the recorded line. The MCP server's
  `lab_resume` sent `--quiet` and was refused by the real Lab every time;
  its fake-door tests now hold the fake to the same rule.
- **MCP progress**: a `lab`/`lab_next` request with `_meta.progressToken`
  gets `notifications/progress` from the Lab's JSON heartbeat.
- **`Settings.reload()` → `Settings.reload_file()`**: on the class the old
  name resolved to Godot's own `Script.reload`, recompiling the script
  instead of re-reading the file.
- **Release tooling**: the Linux smoke boot reads the exit-time leak line
  as the macOS one does; the desktop shortcut launches from a folder whose
  path holds a `%` (sh is the program there — checked with `gio launch`).
