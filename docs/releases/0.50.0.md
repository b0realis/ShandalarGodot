# Shandalar 0.50.0

*"Bump major version to 0.50.0 and we will go 0.50.1 and on."* — the
owner, on the 0.40.57 build. The 0.50 line opens on the game 0.40.57
is; nothing in it changed between the two numbers.

- **What the 0.40 line brought**, 0.40.3 to 0.40.57: Pack 6 (Portal,
  Portal Second Age) and Pack 7 (Fifth Edition); the rules presets as
  data; the AutoDeck builder with its mana-analysis page and its
  command line; the Deck Lab's tournament mode, its fan-out and its
  resume; the tools for a program — `AGENTS.md`, `--dry-run`,
  `--record`, the referee, the one door `shandalar.sh` and the MCP
  server behind it; the controls layer (pad pointer, rebinding, the
  Steam Deck release); the Meta Quest package and its three headset
  reports; the card pool compiled off the title and the presses that
  wait for it; the owner's sixteen portraits; and the Magic Battle
  press that reads each deck once.
- **The version sites** — `project.godot` and the two SGManalink
  documents — name 0.50.0. Menu labels, tool banners, package names
  and SGManalink's compatibility stamp read it from there, so LAN peers
  must match it as before; the wire protocol stays 24.
- No code change. The next commit is 0.50.1.
