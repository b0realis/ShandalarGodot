# Shandalar 0.60.3

Mini cards in the adventure deck builder now show their complete card
frames as soon as the deck opens. The borders stay visible while viewing
a deck outdoors or editing it in town, without removing and adding cards
again. The fix supports both the classic and high-resolution skins; no
replacement skin is needed.

This update includes the [0.60.2 adventure playtest improvements](0.60.2.md).
For LAN games, use matching game versions and card packs on every machine.
