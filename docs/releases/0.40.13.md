# Shandalar 0.40.13

- Pack 7 — Fifth Edition (`7-5ED`): the 1997 core set as a card pack,
  434 names across 449 original English printings, four illustrations for
  each basic land. Every card is a reprint of the base game or of Packs
  2 to 4, so the pack adds pictures and a Fifth Edition source for 147
  Ice Age, Homelands and Fallen Empires cards, never a rule of its own.
  Gold Roman V emblem, Extras medallions, an Options block, `5ed:<n>`
  card variants for the basic lands. Build locally with
  `python3 tools/pack_7_fifth_edition.py fetch-art`, then
  `python3 tools/pack_7_fifth_edition.py`; the ZIP and artwork stay local.
- A card Fifth Edition shares with Ice Age, Homelands or Fallen Empires
  plays with either pack installed; the original expansion's script is
  the one that runs when both are on, and disabling one pack only warns
  when the deck would lose its last provider.

No wire change: protocol 24 peers interoperate.
