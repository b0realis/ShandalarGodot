# Shandalar 0.70.11 — the robustness release

## Controller

- **The whole game can be played with a controller.** On the world map the D-pad walks your hero like the arrow keys: held, step by step, two directions for a diagonal. The left stick still moves the pointer and A walks there. In a town, a menu or any other pane the D-pad jumps from button to button, A presses and B closes.
- **The adventure has its own buttons.** Y opens the map, Back your hero and tasks, Start the options, RB stops and finds your hero, X takes a pane's first choice, and the right stick press reads the card under the pointer. All can be changed in **Options → Controls → World map**, which also says how the map is walked with keys, mouse and pad.
- **Every other screen answers the pad too.** B closes or cancels everywhere, LB and RB turn Help's pages, Start opens the Deck Builder's menu, scrolling texts scroll under the D-pad, text fields bring up the on-screen keyboard, and a file chooser opened by pad is one the pad can use. Typing a new file name in a file chooser still needs a keyboard, and Android keeps the system's own file picker.
- With no controller connected nothing changes. F10 now opens the options on the world map.

## Adventure

- **An empty deck no longer ends an adventure.** Leaving the deck editor on an empty deck slot used to end the adventure at the next creature, and the autosave ended it again. The game now switches to a deck that plays, or fills one from your cards, and tells you. A save already caught in this is rescued when it is loaded.
- **The Old Adventurer's Hut no longer makes the map stutter** while the pointer rests on it.
- **The first voyage to an island no longer freezes the game**, and card shops open faster.
- **The browser version can start a new adventure again** on browsers without threads.
- **On phones and headsets the adventure is saved when the app is paused.**
- **A long text in a place's pane scrolls** instead of running off the screen.
- **A conceded adventure duel is filed in Past Games as a loss**, not as incomplete.

## Duel

- **Smoother cards and menus.** A dash, an accent or an arrow in a text no longer costs a stutter each time it is drawn: the large card, the menus and Help all gain. Help opens several times faster with the 1997 skin.
- **LAN duels and replays redraw two to four times faster** in the mid game, and the Spell Chain is no longer rebuilt on every redraw.
- **The coin toss and the end-of-duel count-down can be hurried** with Space, Return, a click or a pad button.
- **A LAN guest who disconnects while reconnecting** no longer leaves the other player waiting five minutes.
- **The computer plays fewer own goals.** It no longer casts Paradigm Shift, Forbidden Crypt or Thought Lash into a position where the card costs it the game; it no longer locks its own winning attack behind Peacekeeper; Flare and Ray of Erasure are aimed at you, not at itself; Rescue is kept for a creature in danger; Planar Collapse and Crater Hellion are not cast when they would mostly destroy its own creatures.

## Decks and card packs

- **Pasted and imported decklists recognize cards whatever their capitals, accents or apostrophes** ("lightning bolt", "Dandan", "Aladdin’s Lamp"). A name that could be two cards is left as a proxy and named.
- **"1000 hands" counts right with proxies and free spells**, and the Hand page no longer shows a single hand's lines above its table.
- **Searching and filtering in the Deck Builder with every pack on is several times faster**, and Magic Battle opens faster.
- **The Card Packs page no longer freezes** when a pack is enabled, disabled or rescanned: an hourglass shows while the cards load.
- **Get Card Packs...** stays responsive as each pack starts, cleans up the downloaded pictures of packs already installed, and its summary scrolls by keyboard and pad.

## Files and safety

- **A crafted zip can no longer get past the size check** on save Import or a card pack.
- **A settings file from someone else can no longer make the game load other files**; such a file is set aside and the defaults are used.
- **Past Games has Delete and Delete all**, and keeps the newest 500 recordings (up to 64 MB). Recordings you imported or named yourself are never removed.
- **"Make the game portable" can be cancelled**, and an interrupted copy leaves no folder behind.
- Leftover half-written files are cleaned up after a day; odd tar archives no longer freeze the window; large photos used as portraits take a fraction of the memory.
- Options returns to the Card Packs button when you come back from that page.
