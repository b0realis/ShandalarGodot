# Shandalar 0.40.18

- Sealed Deck: the dialog now has a card pool. Tick the sets the packs
  are dealt from — one expansion alone, or any mix of the sets in play —
  with Select All and Clear All beside the grid; the pool line names the
  sets and the sheet, the choice is remembered, and an empty pool is
  refused with a word rather than an empty deal. A tournament for one set
  can now be simulated the way AutoDeck already built for one.
- Deck Lab: `--packs LIST` enables card packs for that run alone — `all`,
  `none`, or ids such as `pack-3,pack-7` (bare `3,7` too). The packs are
  enabled in memory; the game's own setting is never touched. The
  settings line and results.json name them, every worker carries them,
  and an unknown word is exit 2 before a game is played. With `--packs
  all` the `decks/tournament/` folder loads 43 of 76 decks (5 before),
  `community/` 61 of 64 and `extended_community/` 14 of 15.
- The AutoDeck command line (`auto_deck.sh` / `auto_deck.bat` beside the
  Lab's launchers; `DeckLab/auto_deck_cli.sh` in the source tree): the
  Deck Builder's AutoDeck by the thousand. Every wish of the window is a
  switch, any switch may list alternatives that the decks walk as a
  cartesian product, each deck gets its own seed the window accepts, and
  the run writes a folder of `.deck` files with `decks.csv` (a row per
  deck: seed, wishes, colours, counts, pool) and `decklist.txt` for the
  Lab's `--matrix`. `--colors random` draws the colours per deck.
  `--packs` is the Lab's own switch, so a field mined from a pack is
  played with the same word.
- A `--matrix DIR` whose decks all lie in subfolders says so instead of
  reporting an empty folder.
- No wire change: protocol 24 peers interoperate.
