# Shandalar 0.50.17

A short round after 0.50.16, most of it from playtesting.

- **The title menu wears the 1997 bullet.** With the 1997 art imported,
  the Celtic-knot square with its pink gem stands at the left of every
  title-menu button, as it did in the original. It lights for the button
  under the pointer, or for the one the arrow keys or the pad have
  reached, whichever you used last, and never for both. Shandalar and
  Save / Load wear it dimmed: they are not built yet, and still say so
  when clicked. Without the imported art the buttons are as they were.
  (Importing again picks up the new art: every frame of the original
  title menu's sprite sheet now comes in with the skin.)
- **Look at the art on the full-screen card.** The card you bring up full
  size now opens with its text in the 1997 box, so the picture is clear.
  **Text: 1997 / Text: full**, beside the card's bottom right, grows the
  box up over the art for a card whose text does not fit, and back; Enter
  does the same (X on ArkOS). The choice is kept for the next card and
  the next launch, and the Deck Builder's own **Text** button for the
  sidebar card is unchanged.
- **Stronghold and Exodus symbols** are closer to the sets' own marks:
  Stronghold an arched gateway with a keystone and a portcullis, Exodus an
  arched bridge with a windowed railing and posts topped with balls.
- **ArkOS: Select opens the pause menu**, so a game can be left from the
  menu's Exit game instead of the power button.
- **A timing log for stutter reports, off unless asked for.** Put an empty
  file named `perf-log` beside the game (on ArkOS in the `shandalar`
  folder), or launch with `SHANDALAR_PERF_LOG=1` or `-- --perf-log`, and
  the game writes what each slow moment was spent on to `logs/perf.log` in
  its data folder and to its output (`portmaster.log` on ArkOS). Delete
  the file and the next launch measures nothing. See `docs/handhelds.md`.
