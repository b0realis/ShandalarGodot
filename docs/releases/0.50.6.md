# Shandalar 0.50.6

The referee hosts a table of its own, so a program — through the MCP
server — can open a game on the LAN and tell a person how to join it.

- **A hosted table.** `DeckLab/referee.sh --host NAME --deck DECK` runs
  the game's own LAN host in-process, opens one table of that name with
  the program in seat 0 and writes a `table` line before anything else:
  `access` (`open`: listed in every Game Browser on the LAN, joined by
  name; `invitation`: listed without its secret, joined by pasting the
  `invitation`), `address`, `port`, the `invitation`, `discovery`.
  `--address` picks one of this computer's private IPv4 addresses (the
  first by default), `--port 0` any free port, `--name` the host's
  nickname, `--wait` (300 s) how long the empty chair is held. The seat
  is marked ready again each time the lobby clears the marks, so the
  duel starts on the guest's own mark; the host stops with the result.
- **`referee_host`.** The MCP tool (`table`, `deck`, `access`, `name`,
  `port`, `address`, `wait`, `turns`, `log`, `packs`, `keep`, `view`,
  `timeout`) answers `pending` with `table` and a note saying how the
  person finds it; `referee_wait` reads on until they sit down, when
  `hello` (`table.hosted: true`) and the first decision arrive. Kept by
  default; the `table` line is replayed before `hello` to a client that
  comes back; `status` lists the game as `hosted`.
- **Joined tables, fixed on the way.** Each lobby wait now has the whole
  `--wait` to itself — one session-wide deadline made every answer after
  that many seconds "never answered", and a joined duel longer than
  `--wait` was lost to refusals. A lobby command the room moved on under
  ("The room changed. Please try again." — the other seat's ready mark
  or deck landing meanwhile) is sent again with the fresh revision, up to
  five times; a game action is still decided afresh. A kept game's client
  knocking while the lobby is waited on is seated then and there, not at
  `hello` when the knock would be stale.
- **Verified live.** One MCP server hosts, a second referee joins by the
  invitation, both seats are played to a shared result inside the gate.
