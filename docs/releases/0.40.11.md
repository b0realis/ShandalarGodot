# Shandalar 0.40.11

- Name the player default on the Options screen: **Modern rules, mana burn
  on** is now a preset of its own, between Modern rules and 1997 — Fifth
  Edition. A fresh install no longer reads "Custom" for a choice nobody
  made; any other mix of the switches still does.
- The duel journal's "Rules:" line names the preset in play.
- Help's ruleset page lists the four choices.

No gameplay change: the switches, their defaults and saved choices are
what they were. Protocol 24 peers interoperate.
