# Shandalar 0.40.33

- **Full-screen card reading:** Options → Display → Full-screen card on click.
  Off by default and remembered. Click or tap the large card in a duel or
  Deck Builder to enlarge it; click again, Escape or controller Cancel closes
  it. Keeps the selected printing and the existing sidebar layout. Local
  computer play waits while reading; network play continues. Hidden hands
  cannot remain visible in the reader.
- **MTG play guide:** rules, fair-information decisions, stack timing,
  tactical combat, twelve worked examples and deck-building strategy in
  `agentic-playgude-mtg.md`. The MCP server exposes `play_guide`, optionally
  selecting chapter 1–16, and the `shandalar://play-guide` resource. Reading
  documentation never starts a duel or accesses hidden state.
- **Handheld packaging:** Steam Deck and experimental ArkOS/RK3326 launchers
  and instructions coexist with the MCP, query and referee launchers. The
  play guide is included in platform packages. These targets still need
  physical-device testing; no Steam Deck Verified claim is made.
- Includes the upstream MCP work through 0.40.32. No engine rules or LAN
  wire changes in this integration; use matching release builds for LAN play.

## Integration checks

Targeted validation: 314 GUT tests / 9,161 assertions across seven UI and
MCP scripts, including the five live MCP checks and a duel played to completion;
84 offline Python tests for the protocol, packages, launchers and publication
guards. All passed. The guide's 16 chapters and local links were checked too.
This was a focused integration pass, not a new full-suite or hardware run.
