# Shandalar 0.40.45

The first Steam Deck playtest report, answered: windows that overflow
the screen, the triggers as mouse buttons for a trackpad hand, and a
Pause menu that flashed.

- **No window past the screen.** Every `OriginalDialog` keeps 24 px
  from the screen's edges: a window made or grown taller than the
  screen is cut to it, recentred, and its body goes behind a vertical
  scroll so the foot buttons stay on the stone and the wheel — a pad's
  right stick — reaches every line (`keep_on_screen`; a D-pad hop
  brings the line it lands on into view and never targets a line
  scrolled away). The six ad hoc viewport clamps in the deck builder's
  Extras and draft windows are gone: the rule is one, in one place.
- **AutoDeck fits a Deck.** The window is 720 tall, not 800; Cards and
  Lands share a row, as do Variety and Seed; its switch lines are one
  row each, so the window is measured honestly the frame it opens; and
  it grows for a pool of more sets than the base eight — fifteen sets
  make a 741-row window under the 752 the screen allows.
- **RT is the left mouse button, LT the right** on the pad layer,
  pulled past half way and let go under a third (a band, so a resting
  finger never clicks twice). A pad click lands wherever a mouse or
  trackpad last put the pointer, else on the focused button: on a Deck
  with the *Gamepad with Mouse Trackpad* layout the right trackpad
  points and RT clicks. `docs/handhelds.md` and the package's README
  recommend that layout.
- **A doubled keystroke is one.** The duel drops the same action again
  within 100 ms from a different kind of device — a Steam Input button
  that sends both the pad's B and an Escape key opened the Pause window
  and closed it in the same instant. A key twice is the player's own
  double tap and stands.
- **Y folds the hand.** `docs/handhelds.md` says what the Y button does
  — folds the hand to name bands, the title showing `[+]` — which is
  what a hand card "shown only by name" most likely was.
- The layer prints each connected pad's name to Godot's log when it
  arrives, for the next report.
- No wire change: protocol 24 peers interoperate.
