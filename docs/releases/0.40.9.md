# Shandalar 0.40.9

- Extend **Pack 6** with **Portal Second Age (1998)**: 155 names / 165
  original English printings, 117 new rules identities. Pack 6 now holds
  318 distinct names and 380 printings; with all six packs enabled the
  catalogue reads 2,359 set entries / 1,898 unique cards.
- Add independent Second Age Extras filters, a procedural gold gate set
  symbol with carved-stone On/Off medallions, three illustrations of each
  Second Age basic land, deck printing preferences and draft selection.
- Ship the five original 40-card Second Age theme decks and the two
  unmodified 30-card starters in their own library group, with three
  illustrated Help pages; the short starters stay casual-only.
- Support Piracy's spell-only borrowed mana, extra combat and main phases,
  whole-damage alternatives and distinct becomes-blocked / becomes-blocker
  transitions in the shared rules. LAN peers require **protocol 24**.
- Computer players plan Second Age choices from public information and
  their own hand only.

Requires a rebuilt `Pack-6-Portal.zip` (`python3 tools/pack_6_portal.py`);
artwork and completed numbered packs are not included in repository or
release payloads. See [the Portal guide](../pack-6-portal.md).
