# Shandalar 0.70.10

- **Pack 1 can be built in the game.** In a downloaded game, **Get Card Packs...** showed Pack 1: DotP Complete as "Not in this build" — its card list was left out of the game's own files. The game now carries it, so every pack and the 1997 card pictures can be made from inside the game.
- **The skin built in the game has its own name.** **Build from a 1997 install...** now keeps its skin as `classic_no-video.zip`. A complete `original_skin.zip` you already have (with the coin-toss and ending movies) is no longer replaced: both stay in your skins folder, and **Choose...** switches between them.
- **A disc that holds only an installer says so.** The skin builder used to call it "not a CD image of the 1997 game"; now it explains that the files are packed inside the installer and asks for the installed folder.
- **Reading a slow disc no longer freezes the window.** The skin builder checks the files beside the window, not in front of it.
- **No connection, no waiting.** When the network is down, the certificate is refused, the server is busy or the card folder cannot be written, **Get Card Packs...** stops and lists the packs it did not start, instead of trying each one in turn. A folder that cannot be written is said before anything is downloaded.
- **A long list of failures stays on the screen** in the card pack window: it scrolls.
- **Options shows folders with spaces whole.** A path such as "Application Support" was cut in the short rows under the skin.
- **The no-skin notice waits its turn.** It no longer opens on top of another start-up notice, and it points to **Build from a 1997 install...** in Options; on Android, Quest and the browser, where that button is not offered, it says so.
- **The skin "?" window scrolls** when many zips are named, so OK stays on the screen.
- **The computer still knows a price is a price.** After 0.70.9's Masticore change the computer could answer "return a basic land unless..." (Ovinomancer and six more cards) as if it were a gain. Fixed.
- **Help names the new buttons.** Embark's card packs page tells of **Get Card Packs...**; the card folder's own README and the Card Packs screen put it first.
