# Shandalar 0.40.56

*"Ok i would like to supply a couple of new portraits with our
release."* — the owner; then a zip of sixteen. The game ships faces of
its own for the first time: the Magic Battle chooser is never empty
again, and nothing of the 1997 game's travels with it.

- **Sixteen portraits ship with the game.** `game/art/portraits/`:
  Assassin, Blue Mage, Druid, Dwarf, Eleian, Elf Archer, Elf Mage, GPU,
  HAL, Necromancer, Necromancer Ghoul, Red Mage, Skeleton Mage, Torte,
  Warchief and White Mage — the owner's own pictures, 138×170 on a
  transparent ground so the stone of the frame shows through, GPL-3.0
  with the rest of the project, each with its SHA-256 row in
  `game/art/README.md` and its line in `Provenance.md`. An install with
  no skin opens the chooser on them instead of on *(no portraits)*.
- **A fourth place for the chooser to look, and it is last.**
  `PortraitLibrary` searched three folders — the player's own, the
  skin's `portraits/`, a dev checkout's — and now a fourth,
  `res://game/art/portraits/`, after the other three. The order is the
  promise: a face of your own, or one cut from your copy of the 1997
  game, still wins over ours on a name clash, and a new name of yours
  joins the list. With a skin imported the chooser shows the seventy
  original faces and these sixteen together; without one, the sixteen.
- **Read through the import pipeline, because a pack has no file to
  open.** A player's portrait is a file the game opens as bytes — it
  arrived after the game shipped. These travel inside the exported pack,
  where the build lists `x.png.import` and no `x.png` (the 0.40.54 APK
  was read to be sure): the listing folds a sidecar's name back to the
  file it stands for and counts the pair once, and a shipped face loads
  through `GameSkin.our_art`, the accessor every other picture in
  `game/art/` goes through. Nothing changes for the player's folders —
  nothing in them wears those suffixes.
- **The inventory holds the folder, both ways.** `tests/ui/test_our_art.gd`
  sweeps `portraits/` as it sweeps the rest: nothing may live there
  that the README does not name, every row is a PNG, and the chooser's
  list of shipped faces must be exactly the rows.
  `tests/ui/test_portrait_library.gd` stages an exported pack's
  listing (`face.png` beside `face.png.import`, and a `ghost.png.import`
  alone) and holds the fold to it; a shipped face is the same texture
  `GameSkin.our_art` hands out; an 8×8 of the player's own outranks it.
- **The player's folder README says so.** *"REPLACING A FACE: a file
  here wins over one that came from your copy of the 1997 game, and over
  one the game ships."* `docs/player-files.md`, `docs/setup.txt` and
  `docs/handhelds.md` name the new last place in the search order.
- No wire change: protocol 24 peers interoperate.
