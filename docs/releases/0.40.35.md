# Shandalar 0.40.35

- **A deck the MCP server wrote is named by its file name** — `write_deck
  {file: "mine.deck"}` puts a deck in the workspace; `lab`, `check_deck`,
  `autodeck`'s `keep`, `referee_start` and `referee_join` now take that
  bare name (a file or a folder in the workspace) and hand the door its
  absolute path. A deck the door finds on its own — an absolute path, a
  path under the checkout or under `decks/` — and every other word
  (`random`) pass through as typed. Building a deck and measuring or
  playing it is one loop again.
- **A path is not a flag** — a refusal's `flag` is the first switch its
  message names; a path segment beginning with a hyphen no longer reads
  as one.
- No wire change: protocol 24 peers interoperate.
