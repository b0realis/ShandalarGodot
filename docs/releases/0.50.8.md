# Shandalar 0.50.8

The export presets, all in the repository.

- **`export_presets.cfg.example` holds every preset now**, the
  `Android Quest` one included — it had lived only in the builder's own
  `export_presets.cfg` since 0.40.48. The example and a working copy now
  differ only in the `<YOUR HOME>` of the six template paths (Linux, web, Android) that name
  the 4.7.stable templates under the builder's home folder; every preset
  excludes `DeckLab/results/*` and `workspace/*` (0.50.7).
- **Why the copy itself stays untracked:** those template paths are the
  builder's home folder, which no tracked file may hold
  (`tools/test_tracked_tree.py`, CONTRIBUTING "Publication"). A new
  machine copies the example and fills in its home, as before.

No engine, card or game change. Gate unchanged from 0.50.7.
