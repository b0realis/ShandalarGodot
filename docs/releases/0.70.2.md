# Shandalar 0.70.2

- **A portable game, from the Options** (asked for in issue #5). Options ›
  Portable game keeps everything the game keeps — your settings, decks and
  adventures, the Hall of Fame, the game records, the skins and card packs
  you added and the logs — in a folder named `portable` inside the game
  folder. **Make this game portable...** copies it all in and starts the
  game again from there; from then on the whole game folder can be copied to
  a USB stick or another computer and played there as it is. **Stop being
  portable...** copies everything back to the computer and renames the
  folder `portable-off`; nothing is deleted. A folder named `portable` made
  by hand works too, starting empty: **Copy this computer's games in...**
  fills it. On Windows, `Shandalar-portable.bat` starts the game portable as
  well (a `userdata\` folder it made before becomes `portable\`). On
  Windows, Linux, macOS, the Raspberry Pi and the Steam Deck; not in the
  browser, on Android, the Meta Quest or ArkOS.
- **Two seats, two territories in Hotseat.** In Magic Battle's Hotseat mode
  each seat chooses its own territory background, color and art, with its
  own preview, and each seat's die rolls its own. Against the computer the
  opponent's half still follows its own deck.
- **Deck Builder: 1997 and All.** The Extras window has two buttons at the
  top: **1997** shows only the original cards, **All** switches every
  source on, or every one off when all are on already.
- **Deck Builder: the Casting Cost, Power and Toughness windows** opened by
  a right-click now keep their **Done** button inside the window.

Measured and tested. Existing skins, card packs and adventure saves remain
usable. For LAN games, use matching game versions and card packs on every
machine.
