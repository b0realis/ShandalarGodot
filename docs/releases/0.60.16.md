# Shandalar 0.60.16

- **The game's own command-line help.** `./run.sh --help` (Linux, Steam
  Deck, Raspberry Pi, macOS) or `Shandalar -- --help` lists the switches
  the game reads, such as the timing log and the Deck Lab tools, and the
  variables it reads. On Windows, use `Shandalar.console.exe -- --help`. A
  bare `--help` given to the game's program itself still lists the
  engine's options.

Measured and tested. Existing skins, card packs and adventure saves remain
usable. For LAN games, use matching game versions and card packs on every
machine.
