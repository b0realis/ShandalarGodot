# Shandalar 0.50.19

From installing 0.50.18 on a Meta Quest 3.

- **The first start's card pack check says what it is doing.** The first
  start after a card pack is added or changed reads every card picture
  in it once and checks it against the pack's manifest. On the headset
  that took six minutes for all nine packs, and the screen showed only
  the splash the whole time, so it looked like the game had stopped. Now
  a screen says "Checking the card packs", which pack of how many and
  how far through it, and that later starts skip this. They do: once a
  pack has passed, it is not read again until the file changes.
- **And the check is faster.** The pictures are now read in one pass
  through each pack's zip. Before, the reader found every picture by
  searching the zip's table from the start. On a desktop, the Tempest
  Block pack's check went from 9.9 to 2.4 seconds. The headset should
  gain at least as much, but that is still to be measured; its start
  report has a line per pack with the time it took.
- **Meta Quest: `push_to_quest.sh` works again.** On current headset
  software, copying a file straight into the game's folder with `adb push`
  fails with "remote fchown failed: Operation not permitted". The script
  now copies each zip into the headset's Download folder, moves it into
  the game's folder on the headset, and checks every file's size on the
  way. It installs or updates the game and keeps its settings and decks.
  It skips any zip the headset already has, so an update copies only
  what changed and the unchanged packs are not checked again.
- **Meta Quest: `quest_fresh_install.sh`, a clean install step by
  step.** It deletes the game and everything it kept on the headset
  (after you type yes), installs it, has you start it once, copies the
  zips, then records the game's log and fetches its start report while
  you start it again. HANDHELD.md has both routes and the commands for
  doing it by hand.
