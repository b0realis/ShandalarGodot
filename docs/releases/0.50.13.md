# Shandalar 0.50.13

A game played through the MCP server against the Wizard, before 0.50.12's
release went out, showed where an agent's seat was still rough; the owner:
*"Yes go, and also do an improvement run on MCP tools … Also good decision
tool will be useful for tools like Jev and Laya - decision models. Lets build
a helper tool for these kind of tools also."*

- **A table summary every turn.** Every referee answer of the MCP server
  carries a compact, readable board as its text — life, hands, permanents
  with their state (tapped, attacking, phased out, attached to), the stack,
  the open prompt with its target ids, the options one per line and the new
  journal lines; `structuredContent` keeps the JSON (`brief`, `full`,
  `delta`, `options`). `text: "json"` keeps JSON as the text.
  `referee_view` re-reads the pending decision in any view.
- **Phased-out permanents and attachments** in the brief and delta views.
- **`until: "mine"`** (recommended) passes through the opponent's turn and
  stops where the seat can act — on their turn only while it holds a
  castable instant or flash spell or a usable ability, named in `stop`;
  `"mine-strict"` never stops on their turn except for its own decisions.
  Journal lines are no longer lost between internal passes, and a decision
  with no choice (an attack with nothing able to attack) is answered for you.
- **One-call casts:** `referee_cast {card, targets}` (targets by id, name,
  `me`/`opponent`), `referee_play_land`, `{"op":"cast"|"activate"}`; a
  refused step is cancelled with the floating mana reported.
- **Options offer only what the engine accepts now** (referee and
  SGManalink): used-up and banned abilities, tapped or sick sources,
  unpayable non-mana costs (Zuran Orb's land), aimless spells and
  unpayable alternative-cost modes are no longer listed; `prepare` refuses
  before any mana is made; `usable_modes` per cast. The checks are the
  engine's own (`MtgGame.ability_announce_refusal`,
  `spell_announce_refusal`, `mana_ability_refusal`), so the two can't
  disagree. Mana burn from a refused activation is gone.
- **The referee** fills an action's missing keys, accepts `autoprepare`
  with `targets` (prepare, pay and submit in one line), names targets by
  card handle or `player:N`, reports `floating` mana on a refusal, and
  takes `--rules modern|modern_mana_burn|fifth`.
- **Decision models.** `tools/decision_menu.py` and
  `tools/shandalar_decide.py`: a numbered menu of complete legal actions
  plus a compact observation (and a documented feature vector), as a Python
  `Env`, a JSON-lines protocol for any language, and the MCP tools
  `referee_menu` / `referee_pick`; random, first and greedy policies; and
  initial support for typed decision models (Laya, Jev): `--policy systemone
  --url` sends each decision as their `/v1/systemone` request — the compact
  state and one `choice` question over the readable menu labels — and plays
  the model's choice (`--systemone` does the same over stdin/stdout).
- **AI:** Time and Tide is cast only when the swap gains something, and in
  answer to a lethal phasing attack.
- `cards` knows every pack the server finds; the network journal writes a
  hidden card in mid-sentence as "a card" ("Wizard draws a card.").

Protocols unchanged: SGManalink 27, referee 1.
