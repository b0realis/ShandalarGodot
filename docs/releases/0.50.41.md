# Shandalar 0.50.41

Packaging improvements on top of [0.50.40](0.50.40.md).

- **Experimental Android ARM64.** A separate phone/tablet export recipe,
  signed-APK checks and plain/classic-skin packages. Android 10 or newer,
  a 64-bit OS and OpenGL ES 3 are the initial support target. Physical
  devices still need testing. Meta Quest remains a separate target;
  this does not add a Play Store release.
- **Optional offline Web packages.** A verified single-threaded Web ZIP
  can gain background caching without changing its engine or adding a
  start screen. The first load needs a connection; subsequent offline
  starts depend on the browser retaining the cached files. Updates wait
  for the running game to close, and incomplete downloads do not replace
  a working cache. Setup instructions stay in a text file.
- **Clearer Web setup.** HTTPS is required when playing from another
  device, including over a local network. HTTP on localhost works for
  same-device testing. Only threaded Web also needs isolation headers.

No duel rules or gameplay changes are included in this patch. Existing
published downloads and release tags are unchanged.
