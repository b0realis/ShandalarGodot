# Shandalar 0.40.31

- **The referee** — `referee.sh` (the game's `--referee`, the door's
  `./shandalar.sh referee`): one duel played through a pipe, a program
  in a seat. Every decision is one JSON line on stdout — the seat, its
  mode, its legal options and its whole view — and the answer is one
  JSON line on stdin, the LAN wire's own actions; a refused answer is
  explained and the same decision asked again; one `result` line ends
  the duel. The seats are the program (both, and it plays itself) and
  the shipped computer players at every level, `unfair` included.
  `--join` seats the same pipe at a table the game hosts — a person,
  or another program — by the LAN invitation or the same-computer
  access code. `--dry-run` prints the plan.
- **`deck_lab.sh --resume OUT`** finishes an interrupted Lab run from
  its checkpoint: the line is read back from `run.json`, the games that
  landed are kept, the rest are played, the report is written as if
  nothing had happened.
- **The one door** lists `referee`; AGENTS.md carries the referee's
  lines and answers, and its session ends by playing the deck it built.
- No wire change: protocol 24 peers interoperate.
