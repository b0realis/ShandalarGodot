# Shandalar 0.50.2

A test-only version. The gate for 0.50.1 ran green on the desk and red
on one of the four CI runners: shard 2 failed
`tests/unit/test_android_corner_2026_09_29.gd` at *"nothing consumed"*.

- **The flag the neighbour left.** The Android corner tracer's test
  asserted that the viewport's input-handled flag was false after the
  tracer saw a key. That flag is only ever reset by a real `push_input`
  — a test that calls `_input` directly reads whatever the previous
  script's last click left there. The desk's six-way deal never put a
  clicking UI script in front of it; CI's four-way deal
  (`LC_ALL=C`, `SHARDS=4 SHARD=2`) did, reproduced in a clean
  `git archive` tree: 133 scripts, 2,087 tests, one failing. The test
  now records the flag before the key and holds the tracer to leaving it
  as found. No game code changed.
