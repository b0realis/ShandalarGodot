# Shandalar 0.40.20

- Deck Lab tournament mode: `--field LIST|DIR|FILE.txt` names the decks
  under test and `--gauntlet LIST|DIR` (or `--deck-b`) the defined good
  decks; every field deck plays every gauntlet deck and `report.txt`
  ranks the field, with `standings.csv` for every deck and `top.txt`
  naming the best `--top N` as the next round's `--field`. A tournament
  never writes the Elo ledger.
- `--group all` plays the whole deck library as a gauntlet; a `.txt`
  deck list is a pool wherever a folder is.
- The AutoDeck command line builds decks and plays no game, and says so;
  a set whose card pack is not in play is refused by pack number, and
  the tool's last line is the tournament to run on what it built, with
  the packs it built from.
- No wire change: protocol 24 peers interoperate.
