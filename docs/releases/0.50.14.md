# Shandalar 0.50.14 — Web startup fix

The single-threaded Web build loads its card pool in the foreground instead
of waiting for an unavailable worker. Deck Builder and duels can open again.
Both Web variants keep startup card/screen resource reads on the browser's
main thread; the threaded engine remains available. Native platforms retain
their background loading.

Two Web packages are available, each plain or with the original skin:

- `web`: ordinary static HTTP(S) hosting, no special headers.
- `web-threaded`: the threaded engine; HTTPS and `Cross-Origin-Opener-Policy: same-origin` plus
  `Cross-Origin-Embedder-Policy: require-corp`. The included
  `python3 tools/serve_web.py --directory .` serves a loopback-only local test.

These corrected Web builds supplement the 0.50.13 release. Its desktop,
handheld and Quest packages remain at their original 0.50.13 source revision;
each package's README names its exact source commit. The Web patch changes
loading and packaging, not card rules. See `setup-web.txt` for hosting.
