# Shandalar 0.40.29

- **`--record losses|stalls|all`** in the Deck Lab writes the engine's
  own log of every admitted game to `OUT/records/` — one file a game,
  `pair0_seed17_a_lost.log`, a `#` header (the decks, pair, seed, who
  was on the play, outcome, turns, line count) and then every draw,
  cast, attack and block, turn by turn. `--record-max N` caps the files
  (50; `0` = no cap); `results.json` / `sweep.json` gain
  `records{filter,max,written,dir}`. The seed in the name replays the
  game.
- **`run.json`** in every `--out` folder, written last whatever the
  exit — 0, 1, the sweep's 4 — by the Deck Lab and the AutoDeck CLI:
  `tool`, `version`, the checkout's `git` commit, the `argv` as typed,
  mode, seed, packs, `started`, `elapsed_seconds`, `exit`, the `files`
  written, a sweep's `control_pass`, and **`next`** — `{why, argv}`, the
  line that would settle what this run left open (matchups still
  straddling even at four times the games, a tournament's top at five
  times against the same gauntlet, a sweep's unclear deltas at four
  times; the AutoDeck's the Lab line that plays the field) or `null`
  when nothing is open.
- **The Lab Query** — `DeckLab/lab_query.sh` (`lab_query.sh` in a
  release, the game's `--lab-query`): `check DECK... [--packs] [--format]`
  reports what the Lab would refuse — every unknown name with the pack
  that supplies it or the nearest real names, the packs needed and
  missing, the format's verdict, `playable`; `packs` lists every pack
  the build knows, found or not, on or not, why not; `cards NAME...` is
  a card's record. One JSON document each; exit 0 for an answer, 2 for
  a line it cannot answer.
- **`./shandalar.sh`**, the one door: `lab`, `autodeck`, `check`,
  `packs`, `cards`, `convert` (`play` in a release), each `exec`ing its
  tool; an unknown verb is refused as one JSON line, exit 2, like every
  tool. A release folder carries `shandalar.sh`, `lab_query.sh` and
  `AGENTS.md` beside `deck_lab.sh` and `auto_deck.sh`.
- The skin-pack scan's `mounted` / `moved` lines go to stderr — the
  0.40.28 play copy printed one ahead of the JSON on stdout.
- No wire change: protocol 24 peers interoperate.
