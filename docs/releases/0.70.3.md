# Shandalar 0.70.3

- **One tune in the Last Refuge's battles.** The pledge duels and the
  Ebon Crown duel were fought with the town's own tune still playing under
  the duel's music. Every adventure duel now plays its own music alone, and
  the town's tune comes back after the battle.
- **Extras in the adventure's Deck Builder.** The Extras window now opens
  in the adventure's Deck Builder too, as a filter of your hero's own
  cards: it lists the 1997 cards and each pack's sets your cards come
  from, so the Fallen Empires or Homelands cards you hold can be shown on
  their own. It never adds a card, and its switches start all on at each
  visit.
- **Only.** Every row of the Extras window, in both Deck Builders, has an
  **Only** button: that set alone, every other source off. The color, type
  and search filters still apply.
- **The big card's type line** stands at the same height on every card,
  with or without a dash in it, and is always a little smaller than the
  card's name, also when a long name is set smaller to fit.

Measured and tested. Existing skins, card packs and adventure saves remain
usable. For LAN games, use matching game versions and card packs on every
machine.
