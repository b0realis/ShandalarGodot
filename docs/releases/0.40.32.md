# Shandalar 0.40.32

- **The MCP server** — `tools/shandalar_mcp.py` (the door's
  `./shandalar.sh mcp`, in a release `python3 tools/shandalar_mcp.py`):
  every tool on one pipe for a program that speaks the Model Context
  Protocol — the packs and the cards, the deck files (written from
  rows and checked by the engine as they are written), the deck
  converter, the AutoDeck CLI, the Lab and its runs (`read_run`,
  `lab_next`, `lab_resume`), and the referee's duel kept as a session
  across calls: one decision answered, the next returned, the board
  rendered brief; a dumb pilot for the decisions a program skips,
  `referee_autoplay` to the end; `referee_join` for a hosted table.
  Twenty-one tools, each described down to its arguments, so a client
  finds them without reading a page; the contract and every manual as
  resources; standard-library Python only. Whatever a tool writes lies
  under the checkout or `workspace/`.
- **The one door** lists `mcp`; AGENTS.md and DeckLab/README.md carry
  the server; the release ships it under `tools/`.
- No wire change: protocol 24 peers interoperate.
