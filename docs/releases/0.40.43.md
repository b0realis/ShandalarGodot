# Shandalar 0.40.43

Browse the bundled deck library and play MTG with your favorite compatible agent.

- Release packages now include the 330 public deck files beside the game, so
  MCP can list and read them without a source checkout or an engine process.
  A reviewed allowlist excludes local decks, ratings and unrelated files.
- `list_decks` supports case-insensitive name/path search, folder filtering
  and optional `offset`/`limit` pagination. Returned paths work with
  `read_deck`, `check_deck`, DeckLab and referee games.
- Slow referee responses no longer leave the previous decision available for
  a duplicate answer. Use `referee_wait` after `pending: true`. Repeated
  refusals still count as one decision, and ended processes release their pipes.
- MCP checks advertised input types and bounds before acting, rejects
  multi-line deck names and fractional card counts, and refuses malformed
  query output instead of reporting a successful empty result.
- Raw and extra command-line arguments follow the same output-path checks as
  structured arguments, including repeated destinations and Elo ledger paths.
  Raw DeckLab runs are unrated unless `rated: true` is requested; resumed and
  recommended runs preserve their recorded settings.

No card rules, difficulty settings or hidden-information boundary changed.
The Web game does not run a local MCP process; use a desktop release for that.
