# Shandalar 0.40.7

- Add optional **Pack 6 — Portal (1997)**: 200 card names, original-printing
  artwork, independent Deck Builder filters and player-facing Help.
- Preserve Portal's large mana symbols in basic-land previews.
- Choose and save card variants in the Deck Builder, including all twenty
  Portal basic-land illustrations and reprints across enabled sets.
- Open the variant chooser from a small floating stone medallion beneath
  the card, preserving the Deck Builder's existing layout and text space.
- Carry artwork preferences into local and LAN duels without changing
  deck legality or revealing hidden cards. LAN peers require protocol 23.
- Redraw Portal's original circular set symbol in gold, with matching
  carved-stone On/Off buttons in Extras.
- Add current card rules, special combat timing, choice prompts and
  public-information computer-player policies for the new set.
- Handle capped blocker groups, library-top movement, next-turn combat
  restrictions and Last Chance's turn-specific loss trigger.
- Correct extra-turn ordering and preserve sacrificed creature power for
  spells that use it.

Requires a matching locally constructed `Pack-6-Portal.zip`; artwork and
completed numbered packs are not included in repository or release payloads.
See [the Portal guide](../pack-6-portal.md) for construction and installation.
