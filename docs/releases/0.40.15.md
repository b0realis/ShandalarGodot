# Shandalar 0.40.15

- The registry-wide sanity check now runs over every card of every pack,
  not only the base pool. Wiitigo (Ice Age) is a printed 0/0 whose whole
  body is the six +1/+1 counters it enters with — a legitimate shape the
  check's exemption list did not know, so it would have flagged the card
  the first time anyone ran it with Ice Age enabled. The exemption now
  names it (a characteristic-defining static, a copy effect, or +1/+1
  counters on entry), and `test_every_card_of_every_pack_is_sane` enables
  all seven packs from the suite's own metadata-only archives and answers
  for all 1,898 identities — one more test, thirteen thousand more
  assertions, a few seconds. The card itself was always right.
- No wire change: protocol 24 peers interoperate.
