# Shandalar 0.60.17

- **A portable game on Windows.** The Windows download now includes
  `Shandalar-portable.bat`. Starting the game with it keeps its settings,
  decks, adventures, Hall of Fame and logs in `userdata\` inside the game
  folder instead of AppData, so the whole game can live on a USB stick.
  Starting `Shandalar.exe` directly works as before.

Measured and tested. Existing skins, card packs and adventure saves remain
usable. For LAN games, use matching game versions and card packs on every
machine.
