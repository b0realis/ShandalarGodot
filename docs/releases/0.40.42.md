# Shandalar 0.40.42

Windows MCP support: play MTG with your favorite compatible agent, without Bash.

- The packaged MCP server discovers `Shandalar.console.exe` and launches card
  queries, deck checks, DeckLab, AutoDeck and persistent referee games directly.
- Windows paths containing spaces and special characters remain separate
  arguments; no shell or batch-file interpreter is involved.
- MCP input and output explicitly use UTF-8, including on non-UTF-8 systems.
- Packages include `VERSION.txt`, generated from `project.godot`, so the native
  server reports Shandalar's version rather than the Godot engine version.
- Windows setup: install Python 3.10+, extract the whole release and point your
  MCP client at `python tools/shandalar_mcp.py` (or `py -3`). Use the full script
  path when the client starts elsewhere. See `AGENTS.md` and the DeckLab manual.
- Deck conversion remains a source-checkout tool; unsupported native commands
  are refused before launching a process. Linux and macOS keep their existing
  shell launchers. No card rules, difficulty or hidden-information boundary changed.

Verification: the pulled baseline passed 8,161 GUT tests. The updated Python
suite passed 394 tests with six skips; the five engine-dependent MCP cases
were also run successfully in the focused Godot integration gate. Native Windows
dispatch, UTF-8 and extracted-package metadata have regression coverage, but
tests on macOS do not establish native Windows runtime compatibility.
