# Portal mechanics inventory

Snapshot: original English Portal, 1997, numbered printings 1–215.
There are 200 names, 27 reprints and 173 new rules identities.

This is an implementation inventory, not a claim that every possible
interaction has an individual regression. The focused card tests exercise
representative families and unusual timing/choices; the complete-game audit
plays five themes under both supported rules presets. All definitions load
without a pending-card guard. See [the pack guide](pack-6-portal.md).
