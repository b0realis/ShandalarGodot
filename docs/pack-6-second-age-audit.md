# Portal Second Age implementation inventory

Checked against the pinned English P02 snapshot (2026-09-24): 165 numbered
printings, 155 names. All names register playable rules; 117 definitions are
new, and 38 reuse existing identities. This inventory describes coverage,
not proof that every possible cross-set interaction has been tested.

Card definitions retain current Oracle text. The set uses normal game rules,
not obsolete Portal-only instructional timing. Helpers cover early-turn
activations, optional triggers and choices, characteristic power, extra
combat, Piracy mana permissions and alternative combat-damage assignments.

Normal computer players use public information and their own hands. They
inspect hidden cards only when resolving a legal look/search effect; the
separate Unfair mode is unchanged. Combat and spell valuations are heuristics,
not a claim of optimal play. Local and LAN duels share the authoritative
rules; protocol 24 carries the new combat choices.

Printed-art limitations and pack totals are in [the pack guide](pack-6-portal.md).
Deck sources are in [the deck guide](portal-second-age-decks.md). Targeted
verification is recorded in the pack guide; no full-suite or release claim.
